# Transactie Manager

Huishoudboekje op basis van je bankafschriften. Lees je afschrift in uit Excel of
CSV, laat de verrichtingen automatisch indelen in categorieën van drie niveaus,
en bekijk per jaar waar je geld naartoe gaat.

- Aanmelden met een eigen gebruikersnaam en wachtwoord, los van Home Assistant.
- Alle persoonsgegevens versleuteld opgeslagen met AES-256-GCM.
- Wachtwoordherstel met een herstelsleutel en een code per e-mail.
- Automatisch indelen via vaste regels, fuzzy vergelijking en eventueel een
  lokaal AI-model.
- Kredietkaartuittreksels in PDF omzetten naar de echte aankopen.
- Jaartabel en grafieken, met filters en uitvoer naar CSV.

Alles blijft op je eigen toestel. Zie het tabblad Documentatie voor de uitleg.
